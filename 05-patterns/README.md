# Модуль 5. Продвинутые паттерны

Serverless, Kubernetes, High-Load, Multi-tenancy для AI-приложений.

## Темы
- Serverless для inference: cold start, scaling to zero, лимиты
- Kubernetes: GPU-операторы, KServe, autoscaling по очереди
- High-Load: батчинг, caching, semantic cache, model routing
- Multi-tenancy: изоляция данных, лимиты, биллинг по тенанту
- Edge / on-prem inference: квантизация, дистилляция
