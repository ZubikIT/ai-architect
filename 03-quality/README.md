# Модуль 3. Качество и безопасность

Тестирование GenAI, интеграции с внешними системами, архитектура данных для AI.

## Темы
- Метрики качества: faithfulness, relevance, groundedness, latency, cost
- Подходы к тестированию LLM: golden sets, LLM-as-judge, A/B
- Безопасность: prompt injection, data leak, PII, jailbreaks
- Архитектура данных: vector store, feature store, lineage, governance
- Интеграции: контракты API, идемпотентность, обработка ошибок
