# Модуль 6. Стратегия и экономика

FinOps, governance, API-дизайн, экономическое обоснование AI-инициатив.

## Темы
- FinOps для AI: модель стоимости (токены, GPU-часы, хранение)
- Unit economics: cost per request, cost per user, маржинальность
- Governance: политики использования моделей, аудит, compliance
- API-дизайн: версионирование, rate limits, биллинг
- Build vs buy vs fine-tune — экономическое сравнение
