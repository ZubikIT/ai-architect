# Разбор курса

Два документа поверх конспектов — то, чего в отдельных уроках нет.

| Документ | Что внутри | Для кого |
|---|---|---|
| [`kurs-polnyy.md`](kurs-polnyy.md) | Сквозной разбор шести блоков: идея урока → где применено → что показал замер. Плюс шесть расхождений курса с замером и семь правил, выведенных из своих ошибок | Себе через год; коллеге, который поведёт такой же проект |
| [`kurs-kratko.md`](kurs-kratko.md) | То же на одну страницу | Перед защитой; в резюме; тому, кто спросил «а что там за курс» |

| [`lms-syllabus.md`](lms-syllabus.md) | Программа внешнего курса «AI-архитектор на практике» для `lms.artcloud.by`: 12 модулей на нашем проекте и наших замерах | Для запуска курса |

⚠ **Разная политика по данным.** Внутренние конспекты и Pages (`pages.acl.by`, доступ только участникам) пишутся **как есть** — с адресами, путями к секретам и именами хостов. Материалы курса **внешние**, и туда идут архитектурные факты без координат: таблица замен — в начале силлабуса. Цифры замеров публикуются полностью, они и есть ценность.

Конспекты уроков лежат по папкам `NN-*` в корне. Проект — в [`final-project/`](../final-project/README.md).
