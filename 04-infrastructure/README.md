# Модуль 4. Инфраструктура

Sizing, MLOps, CI/CD, высокая доступность для AI-нагрузок.

## Темы
- Sizing: GPU/CPU/RAM под inference и training, batch vs realtime
- MLOps: жизненный цикл модели, версионирование, мониторинг дрейфа
- CI/CD для ML: тесты данных, тесты модели, канареечный rollout
- HA: реплики, очереди, retries, circuit breakers
- Observability: метрики, трейсинг, логи запросов и ответов модели
