# Модуль 2. Проектирование архитектуры

HLD/LLD для AI-систем, паттерны RAG, AI-агенты и Multi-Agent Systems.

## Темы
- High-Level Design: контекст, контейнеры, основные потоки
- Low-Level Design: компоненты, API, схемы данных
- RAG: индексация, retrieval, reranking, генерация
- AI-агенты: tool use, планирование, память
- Multi-Agent Systems: оркестрация, коммуникация, конфликты
