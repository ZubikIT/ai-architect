# 08. Документирование решений: Architecture Decision Records (ADR)

## TL;DR

## Контекст и проблема
_Зачем формализовать архитектурные решения, чем ADR лучше «всё в голове / в Confluence»._

## Структура ADR
- Контекст и силы давления
- Рассмотренные варианты
- Решение
- Последствия (плюсы / минусы / риски)
- Статус (proposed / accepted / deprecated / superseded)
- Связи между ADR

Шаблон уже есть: [`../../templates/adr.md`](../../templates/adr.md).
