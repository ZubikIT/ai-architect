## Решение

### Подход
- **Топология:** supervisor / pipeline / hierarchical — выбрать и обосновать (для делегирования «Менеджер → Поисковик» естественен **Supervisor / Orchestrator**).
- **Состав агентов и роли** (Single Responsibility):
  - Менеджер (Supervisor) — приём задачи, декомпозиция, делегирование, сборка итога.
  - Поисковик билетов — поиск авиа/ж-д вариантов (tool: search API).
  - Аналитик бюджета — проверка против политики командировок (**RAG** по внутренним регламентам).
  - Бронировщик отелей — подбор/бронь в рамках лимита.
- **Набор инструментов (tools)** для каждого агента.
- **RAG Flow:** источник = политика командировок компании; чанкинг → эмбеддинг → (гибрид + реранжинг) → контекст для Аналитика бюджета.
- **Память:** краткосрочная (контекст диалога) + долгосрочная (состояние задачи).
- **Ограничения и safety-net:** лимиты циклов, бюджет токенов, human-in-the-loop на подтверждение брони.
