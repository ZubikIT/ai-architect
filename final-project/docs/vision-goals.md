# Vision & Goals

> **Редакция 1.0 переписана целиком.** Черновик 0.1 описывал вымышленный контур: 2× H100 NVL, Open WebUI как окно сотрудника, Onyx как коннектор к Confluence/Jira/SharePoint. Ни одного из этих трёх решений в реальности нет — карта расхождений в [`adr-audit.md`](adr-audit.md). Здесь — vision **работающей платформы** под тему работы.

## Что это за система

**Предмет проекта — закрытый контур платформы ZubrIQ:** доступ к языковым моделям в юрисдикции Республики Беларусь. Платформа обслуживает реальных клиентов, считает потребление и выставляет счета в BYN. Описание as-is — [`../../zubriq-platform/`](../../zubriq-platform/README.md).

Платформа **гибридная**: рядом с закрытым контуром работает коммерческий внешний режим через агрегатора. Предметом работы объявляется только закрытый контур — свои модели на своём инференсе, нулевой egress. Граница физическая и проверяемая: поле `models` у ключа, проверка стоит в шлюзе **до** обращения к вендору ([ADR-0020](adr/0020-dva-rezhima-dostupa.md)).

## Vision

Превратить платформу доступа к моделям в **платформу цифровых сотрудников**: не «чат, который отвечает по документам», а набор ролей с собственными правами, каждая из которых отвечает за свою область корпоративных знаний и не может дотянуться до чужой.

Три свойства, которые эту систему определяют и без которых она перестаёт быть собой:

1. **Право на ответ проверяется на каждом узле пути к ответу**, а не на выходе. Документ, до которого субъект дошёл по связи из разрешённого документа, всё равно проверяется на доступ — иначе граф знаний становится обходным путём вокруг прав ([ADR-0016](adr/0016-acl-na-uzlah-grafa.md)).
2. **Отказ — такой же правильный ответ, как и ответ.** Система, которая всегда что-нибудь выдаёт, для нормативной области опаснее молчащей: ответ с цитатами убедителен ровно в той мере, в какой он неверен.
3. **Данные не покидают юрисдикцию.** Это не декларация, а то, что клиент покупает.

## Цели

| № | Цель | Как проверяется | Состояние |
|---|---|---|---|
| **Ц-1** | Ответ по корпоративным ЛПА **со ссылкой на пункт** и с учётом отменяющих редакций | golden set: context recall, пометка об отмене | ✅ recall 1,0 · пометка 1,0 |
| **Ц-2** | **Права соблюдаются на всём пути**, включая связи графа | golden set: нарушений ACL; тест «User B» на обоих путях | ✅ 0 нарушений |
| **Ц-3** | **Честный отказ** там, где ответа для этой роли нет | гейт `refusal_pass` | ✅ 1,0 — и это **гейт приёмки**, [разбор](eval-report.md#гейт-честный-отказ-и-почему-прежний-эталон-был-неправ) |
| **Ц-4** | **Роли-агенты с собственным мандатом прав**, а не один ассистент с общим доступом | точность маршрутизации; тест least privilege | ✅ 13/13 · права агента ⊆ прав пользователя |
| **Ц-5** | **Нулевой egress** закрытого контура | поле `models` у ключа, проверка до вызова | ✅ работает в проде |
| **Ц-6** | Предсказуемая экономика **без переменных платежей за токены** | [TCO](economics/tco.md) | ⚠️ ~$42,5k за 3 года; **утилизация не измерена** — главный неизвестный |
| **Ц-7** | Сквозная наблюдаемость: `request_id` открывает трейс | `trace_id == request_id`, разложение по шагам | 🟡 есть в [`backend/`](../backend/), **в платформе сквозного трейсинга нет** |

Строка Ц-7 намеренно оставлена жёлтой: у платформы есть трассировка вызовов моделей и метрики, но инциденты разбираются сопоставлением по времени. Это названо и в [ADR-0017](adr/0017-observability.md), и в [техдолге](../../zubriq-platform/docs/operations.md#известный-техдолг).

## Не-цели

- **Внешние модели в предмете проекта.** Коммерческий режим существует и приносит выручку, но в периметр работы не входит и отсекается правами ключа.
- **Обучение foundation-модели с нуля.** Дообучение — да: [Zubr-VL-32B](../../zubriq-platform/docs/platform.md) обучена QLoRA на праве РБ. Но факты в веса не зашиваются, для этого есть retrieval.
- **Замена оператора и юриста.** Система суфлирует и цитирует; решение принимает человек. Для нормативной области это не осторожность, а требование.
- **Мульти-регион и мульти-облако.** Целевой деплой — своё железо в одной юрисдикции; это и есть продукт.
- **Свой чат-UI с нуля** — уже есть, React + Vercel AI SDK, API внутри консоли ([ADR-0025](adr/0025-svoy-chat-vmesto-dorabotki-chuzhogo.md)).

## Стейкхолдеры

| Кто | Что ему нужно | Чем это обеспечено |
|---|---|---|
| **Сотрудник-пользователь** | быстрый ответ по ЛПА со ссылкой на пункт | GraphRAG, цитирование, пометка об отмене |
| **Оператор КЦ** | подсказка быстрее, чем клиент договорит вопрос | p50 177 мс на retrieval-части ([замер](load-report.md)) |
| **Служба ИБ** | доказательство, что чужое не выдаётся | ACL на узлах, 0 нарушений на golden set, единый текст отказа |
| **Юрист / комплаенс** | действующая редакция, а не отменённая | рёбра `ОТМЕНЯЕТ` в графе, пометка в ответе |
| **Инженер платформы** | понять, почему у клиента было медленно | `request_id` = `trace_id`; **в платформе пока не работает** |
| **Владелец продукта** | себестоимость запроса | [TCO](economics/tco.md); упирается в неизмеренную утилизацию |
| **Клиент платформы** | данные остаются в юрисдикции | граница по полю `models`, проверка до вызова |

## Метрики успеха

**Измерено:**

| Метрика | Значение | Источник |
|---|---:|---|
| Context recall | 1,0 | [golden set](eval-report.md) |
| Context precision | 0,215 | там же |
| Нарушений ACL | 0 | там же |
| Точность маршрутизации | 13/13 | там же |
| Faithfulness (судья ≠ подсудимый) | 0,923 | там же |
| p50 ответа без генерации | 177 мс | [нагрузочный отчёт](load-report.md) |
| RPS на 8 клиентах | 11,03 | там же |

**Не измерено, и это влияет на выводы:**

- **Утилизация инференса измерена: 0,9 %** за 30 дней. Фактическая цена 1M выходных токенов — ~$142 по инфраструктуре и ~$605 с ФОТ, против $0,3–2 у внешнего вендора. Контур покупается ради юрисдикции, а не ради цены.
- **Adoption и польза** — доля принятых подсказок, сокращение времени ответа клиенту. Нужны операторы и рабочий трафик, на демо-корпусе не получить.
- **Качество на большом разнородном корпусе.** Четыре ЛПА и 19 чанков — этого хватает, чтобы доказать свойства (права, отмены, отказ), и не хватает, чтобы судить о качестве ранжирования.

## Ограничения

- **Железо фиксировано и скромнее проектного:** 4× Tesla V100 SXM2 по 16 ГБ вместо 2× H100 NVL. Отсюда MoE-модель в AWQ вместо плотной ([ADR-0002](adr/0002-vybor-modeli.md), [ADR-0006](adr/0006-kvantovanie-i-sizing-gpu.md)).
- **VRAM эксклюзивна.** Пилотная модель и прод на одном боксе не сосуществуют — юниты объявляют взаимное исключение. Следствия этого в первоначальном ADR не было вовсе.
- **Инференс без резерва.** Один GPU-бокс: его отказ убирает закрытый режим целиком, при этом внешний продолжает работать — деградация неочевидна для пользователя.
- **Юрисдикция РБ, Закон № 99-З**, санкционные ограничения на зарубежный SaaS.
- **Команда с начальными ML-компетенциями** → ставка на готовые компоненты с большими сообществами, а не на своё.
