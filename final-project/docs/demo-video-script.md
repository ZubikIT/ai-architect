# Сценарий видео-демонстрации (5–7 минут)

> Формат сдачи по ТЗ требует видео-демо на 5–7 минут с **трейсами**, **логами vLLM** и **графом в браузере Neo4j**. Здесь — раскадровка: что показывать, чем показывать и что говорить. Записывается одним дублем с экрана; голос — по правой колонке, без чтения слайдов.

## Терминальная часть — записывается автоматически

Демонстрация **поднимает свой сервер и работает через его API** — так же, как
[демо ZuBrIQ Gateway](https://zubriq.by/demo/gateway) на витрине. Не набор
CLI-вызовов, а живой сервис: скрипт запускает `uvicorn`, дожидается `/healthz`
и дальше раскрывает возможности одну за другой.

| # | Шаг | Что показывает |
|---:|---|---|
| 1 | `uvicorn` + ожидание `/healthz` | сервис поднялся; `auth=dev` виден снаружи намеренно |
| 2 | `GET /graph/stats` | граф собран поверх корпуса: узлы, документы, рёбра |
| 3 | `POST /ask` | вектор нашёл ЛПА-01 (28 дней), пометку об отмене принёс граф |
| 4 | тот же вопрос при `SUFLER_GRAPH=0` | **контрольный замер**: пометка исчезла, ответ уверенно неверен |
| 5 | `POST /ask` с ролями `all` и `legal` | **критерий ТЗ «пользователь B»**: две выдачи, ЛПА-03 только у `legal` |
| 6 | `POST /ask/stream` | SSE: `sources` уходят **раньше** первого `token` |
| 7 | `GET /agents` | штат цифровых сотрудников и мандаты ролей |
| 8 | `POST /agents/ask` | маршрут супервизора, израсходованный бюджет, права агентов |
| 9 | `POST /v1/chat/completions` | OpenAI-совместимость — подключается как модель |
| 10 | `pytest` | 42 теста на графе, правах и MAS — прямо в кадре |

```bash
cd final-project/backend
.venv/bin/pip install asciinema pyte pillow imageio-ffmpeg     # тулчейн pip-only
.venv/bin/asciinema rec --cols 100 --rows 34 --overwrite \
    -c "bash ../docs/demo/demo.sh" ../docs/demo/demo.cast
.venv/bin/python ../docs/demo/cast2mp4.py ../docs/demo/demo.cast \
    ../docs/demo/demo.mp4 --fps 10 --idle 4.0
```

Порт выбирается свободный автоматически, сервер глушится по `trap` на выходе.
Режим офлайн (`SUFLER_USE_LLM=0`): retrieval, граф, права и стриминг работают
полностью, генерация собирается экстрактивно — **GPU не нужен**.

> **Что лежит в репозитории.** `.gitignore` отбивает `*.mp4`, но для
> [`demo/demo.mp4`](demo/demo.mp4) сделано исключение: видео — требование формата
> сдачи по ТЗ, и комиссия должна получить его вместе с репозиторием, а не
> собирать из записи. Рядом остаётся [`demo/demo.cast`](demo/demo.cast) — из неё
> видео пересобирается одной командой, она воспроизводится через
> `asciinema play demo.cast` и читается глазами как обычный JSON: диффы по ней
> осмысленны, в отличие от mp4. 64-колоночная версия идёт на витрину как `.cast`,
> её mp4 в git не нужен.

### Версия под плеер витрины (64 колонки)

Та же демонстрация, свёрнутая под мини-плеер продуктовых страниц
(`TerminalDemo.astro`, конвенция `site/scripts/cast/README.md`: ширина 64, чтобы
строки умещались на мобильном):

```bash
.venv/bin/asciinema rec --cols 64 --rows 26 --overwrite \
    -c "bash ../docs/demo/demo-64.sh" ../docs/demo/demo-64.cast
```

Отличия от широкой версии — только в подгонке под кадр, сценарий тот же: полный
URL заменён коротким `$A`, вывод режется `cut -c1-62`, подписи сокращены.
Проверка ширины: строк, упирающихся в правый край, **7 из 35** — и все семь это
эхо команд, а не вывод. Готовый [`demo-64.cast`](demo/demo-64.cast) кладётся на
страницу как есть: формат совпадает с `public/*-demo.cast`.

**Чего в терминальной записи нет и что нужно доснять с экрана:** граф в браузере
Neo4j, трейс в Jaeger по `request_id`, дашборд Grafana. Это кадры ниже — они
требуют поднятого стека и GPU-бокса.

### Cypher для кадра 4 — проверено, отдаёт строки

Свойство узла `Чанк` называется `doc_code` (не `code` — на `code` вернётся
`NULL` и в кадре будут пустые подписи):

```cypher
// отмена: кто кого — одна строка, читается вслух
MATCH (a:Чанк)-[:ОТМЕНЯЕТ]->(b:Чанк)
RETURN a.doc_code + ' · ' + a.section AS отменяющий,
       b.doc_code + ' · ' + b.section AS отменённый;
// → "ЛПА-04 · 1. Продолжительность отпуска" отменяет "ЛПА-01 · 1. Продолжительность отпуска"

// картинка целиком: документы по краям дают читаемые подписи
MATCH p=(d:Документ)-[:СОДЕРЖИТ]->(:Чанк)-[:ОТМЕНЯЕТ]->(:Чанк)<-[:СОДЕРЖИТ]-(d2:Документ)
RETURN p;

// ACL на узлах — для кадра 5
MATCH (c:Чанк {doc_code:'ЛПА-03'})-[:ДОСТУПЕН_РОЛИ]->(r:Роль)
RETURN c.section AS раздел, collect(r.name) AS роли;
// → у всех разделов ЛПА-03 роли ["legal","security"] — роли all там нет
```

**Важная деталь, которую легко сказать неверно:** ребро `ССЫЛАЕТСЯ_НА` ведёт из
**чанка в документ**, а не из чанка в чанк — `ЛПА-02 · 3.1 → документ ЛПА-03`.
Всего в графе: `ДОСТУПЕН_РОЛИ` 29, `СОДЕРЖИТ` 19, `ССЫЛАЕТСЯ_НА` 3, `ОТМЕНЯЕТ` 1.

### Jaeger для кадра 7

Сервис в поиске — **`platform-backend`**. Трейс запроса `/ask` содержит 12 спанов;
разбор, который видно в кадре и который стоит назвать вслух:

```
ask 2763 мс
├─ guardrail.input      0,0 мс
├─ retrieve            1204 мс
│  ├─ retrieve.embed      81 мс
│  ├─ retrieve.hybrid   1122 мс  ├─ retrieve.dense 3,9 мс · retrieve.bm25 0,2 мс
│  │                             └─ retrieve.rerank 1036 мс  ← основное время
│  ├─ graph.expand       6,0 мс  ← обход графа
│  └─ graph.annotate     2,8 мс
├─ llm.generate        1559 мс
└─ guardrail.output     0,1 мс
```

Это же — числовая опора для слайда «где время»: реранк и генерация, граф — единицы
миллисекунд.

### Grafana для кадра 9

`http://localhost:3000/d/graphrag-platform`, дашборд «GraphRAG и цифровые
сотрудники», 16 панелей. После прогрева: доля ответов **с пометкой об отмене
1,00**, **с вкладом графа 1,00**, обход графа p95 **≈ 20 мс**, латентность p95
**≈ 3,6 с**, доля ошибок **0**, честных отказов **5**, нарушений ACL **0**.

Единица в двух первых панелях — не украшение и не ошибка: демо-корпус из четырёх
документов построен вокруг отменённой нормы, поэтому её касается каждый
отвеченный вопрос. Отказы в знаменатель не входят — они не считаются ответами.
Если спросят, честный ответ такой, а не «у нас всегда сто процентов».

Панели `Срабатывания guardrails` и `Отклонённые токены` останутся пустыми: эти
счётчики принадлежат слою платформы, а не контуру проекта — тот самый разрыв,
про который отдельный слайд в деке. Не выдавать пустоту за ноль.

### Логи vLLM для кадра 8

Записываются **с GPU-бокса**: по ssh с рабочей машины вход закрыт
(`Permission denied (publickey,password)`), проверить заранее отсюда нельзя.
Открыть `journalctl -u vllm -f` на самом боксе и держать кадр в момент запроса.

Имя модели в логах будет `qwen3.6-35b` даже после обновления весов — это алиас
на `Qwen3.8-27B-AWQ-INT4`, vLLM возвращает первое из служебных имён. Если кадр
попадёт в запись, назвать это вслух, иначе выглядит как несоответствие деке.

## Раскадровка

| # | Время | Кадр | Что делаю | Что говорю |
|---:|---|---|---|---|
| 1 | 0:00–0:30 | терминал | `python -m sufler.cli --stats` | Закрытый контур: свои модели, свой инференс. Корпус ЛПА, граф связей поверх него — столько-то узлов и рёбер |
| 2 | 0:30–1:20 | терминал | `python -m sufler.cli "Сколько дней основной ежегодный отпуск?"` | Вектор находит ЛПА-01 с 28 днями. В ответе — **30 дней и пометка об отмене**: её принёс обход графа, а не поиск |
| 3 | 1:20–1:50 | терминал | `SUFLER_GRAPH=0 python -m sufler.cli "…"` · рядом — тест `test_graph_disabled_loses_the_annotation` | **Контрольный замер**: выключаю граф — пометка исчезает, ответ становится уверенно неверным. Это и есть доказательство пользы |
| 4 | 1:50–2:40 | Neo4j Browser | `MATCH p=(:Чанк)-[:ОТМЕНЯЕТ]->(:Чанк) RETURN p` и раскрытие `ССЫЛАЕТСЯ_НА` | Четыре типа узлов, рёбра извлечены правилами. Вот то ребро, которое меняет ответ |
| 5 | 2:40–3:40 | терминал, два запуска | `--roles all` и `--roles legal` на вопросе про ПДн | **Критерий «пользователь B»**: один вопрос, две роли. Закрытый ЛПА-03 в выдачу роли `all` не попадает — и не попадает **транзитом по ссылке**: закрытый узел для неё не существует |
| 6 | 3:40–4:20 | браузер, SSE | `curl -N` на `/ask/stream` | Источники уходят **раньше первого слова** ответа: пользователь сразу видит основания |
| 7 | 4:20–5:10 | Jaeger | вставляю `request_id` из ответа в поиск | `request_id` — это и есть `trace_id`. Разложение по шагам: реранк, обход графа, генерация. Содержимое запроса в трейс не пишется |
| 8 | 5:10–5:40 | логи vLLM | `journalctl -u vllm -f` в момент запроса | Движок в контуре, нативно из systemd: видно приём запроса, батч, токены. Наружу не уходит ничего |
| 9 | 5:40–6:20 | Grafana | дашборд «GraphRAG и цифровые сотрудники» | Golden Signals и **доля ответов со сработавшим ребром `ОТМЕНЯЕТ`** — метрика, которая ловит «граф перестал работать» |
| 10 | 6:20–6:50 | терминал | `python -m tools.eval` (из `backend/`) | Гейты приёмки: recall, нарушения ACL, пометка об отмене, честный отказ. Прогон возвращает код 1 при провале — готовый шаг CI |

## Чего в кадре быть не должно

- реальные адреса контура, пути Vault, токены и пароли в терминале (`export` с паролем — вне записи);
- содержимое закрытых документов сверх демо-корпуса `backend/data/lpa/`;
- пустые экраны: если Jaeger не успел принять спан, повторить запрос до начала записи, а не в кадре.
