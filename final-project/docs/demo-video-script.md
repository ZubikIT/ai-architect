# Сценарий видео-демонстрации (5–7 минут)

> Формат сдачи по ТЗ требует видео-демо на 5–7 минут с **трейсами**, **логами vLLM** и **графом в браузере Neo4j**. Здесь — раскадровка: что показывать, чем показывать и что говорить. Записывается одним дублем с экрана; голос — по правой колонке, без чтения слайдов.

## Терминальная часть — записывается автоматически

Кадры 1–5 и 10 (CLI, контрольный замер без графа, «пользователь B», тесты) собраны в
скрипт и пишутся в mp4 без ручной работы, офлайн, без GPU:

```bash
cd final-project/backend
.venv/bin/pip install asciinema pyte pillow imageio-ffmpeg     # тулчейн pip-only
.venv/bin/asciinema rec --cols 100 --rows 32 --overwrite \
    -c "bash ../docs/demo/demo.sh" ../docs/demo/demo.cast
.venv/bin/python ../docs/demo/cast2mp4.py ../docs/demo/demo.cast ../docs/demo/demo.mp4
```

Результат — `demo/demo.mp4`, **66 секунд**, 1020×692. Паузы на загрузку весов обрезаются
рендерером до пяти секунд, поэтому видео втрое короче реального прогона (3 мин 11 с).

> **mp4 в git не хранится** — `.gitignore` отбивает бинарники, и правильно: в репозитории
> лежит запись [`demo/demo.cast`](demo/demo.cast) на 8 КБ, из которой видео пересобирается
> одной командой. Она же воспроизводится в терминале через `asciinema play demo.cast` и
> читается глазами как обычный JSON — в отличие от mp4, диффы по ней осмысленны.

**Чего в терминальной записи нет и что нужно доснять с экрана:** граф в браузере Neo4j,
трейс в Jaeger, дашборд Grafana, потоковый ответ. Это кадры 4, 6, 7, 8, 9 ниже — они
требуют поднятого стека и GPU-бокса.

## Перед записью

```bash
cd final-project/infra
cp .env.example .env                                    # пароли; в контуре — из Vault
docker compose --profile core --profile obs up -d       # знания + приложение + наблюдаемость
cd ../backend
export NEO4J_URI=bolt://localhost:7687 NEO4J_PASSWORD=... QDRANT_URL=http://localhost:6333
export OTEL_EXPORTER_OTLP_ENDPOINT=localhost:4317
python -m sufler.cli --stats                            # граф собран: узлы, рёбра, чанки
uvicorn sufler.api:app --port 8080
```

Открытые вкладки: Neo4j Browser `:7474` · Jaeger `:16686` · Grafana `:3000` · терминал с `journalctl -u vllm -f` на GPU-боксе · терминал с `curl`.

Проверить до записи: `--stats` показывает непустой граф; `/healthz` отвечает; в Jaeger есть хотя бы один свежий трейс (иначе видно будет пустой экран).

## Раскадровка

| # | Время | Кадр | Что делаю | Что говорю |
|---:|---|---|---|---|
| 1 | 0:00–0:30 | терминал | `python -m sufler.cli --stats` | Закрытый контур: свои модели, свой инференс. Корпус ЛПА, граф связей поверх него — столько-то узлов и рёбер |
| 2 | 0:30–1:20 | терминал | `python -m sufler.cli "Сколько дней основной ежегодный отпуск?"` | Вектор находит ЛПА-01 с 28 днями. В ответе — **30 дней и пометка об отмене**: её принёс обход графа, а не поиск |
| 3 | 1:20–1:50 | терминал | `SUFLER_GRAPH=0 python -m sufler.cli "…"` · рядом — тест `test_graph_disabled_loses_the_annotation` | **Контрольный замер**: выключаю граф — пометка исчезает, ответ становится уверенно неверным. Это и есть доказательство пользы |
| 4 | 1:50–2:40 | Neo4j Browser | `MATCH p=(:Чанк)-[:ОТМЕНЯЕТ]->(:Чанк) RETURN p` и раскрытие `ССЫЛАЕТСЯ_НА` | Четыре типа узлов, рёбра извлечены правилами. Вот то ребро, которое меняет ответ |
| 5 | 2:40–3:40 | терминал, два запуска | `--roles all` и `--roles legal` на вопросе про ПДн | **Критерий «пользователь B»**: один вопрос, две роли. Закрытый ЛПА-03 в выдачу роли `all` не попадает — и не попадает **транзитом по ссылке**: закрытый узел для неё не существует |
| 6 | 3:40–4:20 | браузер, SSE | `curl -N` на `/ask/stream` | Источники уходят **раньше первого слова** ответа: пользователь сразу видит основания |
| 7 | 4:20–5:10 | Jaeger | вставляю `request_id` из ответа в поиск | `request_id` — это и есть `trace_id`. Разложение по шагам: реранк, обход графа, генерация. Содержимое запроса в трейс не пишется |
| 8 | 5:10–5:40 | логи vLLM | `journalctl -u vllm -f` в момент запроса | Движок в контуре, нативно из systemd: видно приём запроса, батч, токены. Наружу не уходит ничего |
| 9 | 5:40–6:20 | Grafana | дашборд «GraphRAG и цифровые сотрудники» | Golden Signals и **доля ответов со сработавшим ребром `ОТМЕНЯЕТ`** — метрика, которая ловит «граф перестал работать» |
| 10 | 6:20–6:50 | терминал | `python -m tools.eval` (из `backend/`) | Гейты приёмки: recall, нарушения ACL, пометка об отмене, честный отказ. Прогон возвращает код 1 при провале — готовый шаг CI |

## Чего в кадре быть не должно

- реальные адреса контура, пути Vault, токены и пароли в терминале (`export` с паролем — вне записи);
- содержимое закрытых документов сверх демо-корпуса `backend/data/lpa/`;
- пустые экраны: если Jaeger не успел принять спан, повторить запрос до начала записи, а не в кадре.
