# Требования (FR / NFR)

> Дополняет [Vision & Goals](vision-goals.md). Обоснования решений — в [ADR-пакете](adr/). Часть NFR-целей зависит от профиля нагрузки (открытый вопрос) — помечены ⚠.

## Функциональные требования (FR)

### FR-1. Персональный ассистент (Open WebUI · [ADR-0007](adr/0007-chat-interface.md))
- FR-1.1 Чат с LLM со стримингом ответа и историей диалогов.
- FR-1.2 Вход через корпоративный **SSO (OIDC)**; роли и доступ — RBAC.
- FR-1.3 Мобильный доступ (клиент **Conduit**).
- FR-1.4 Загрузка личных документов и RAG по ним (персональная плоскость).

### FR-2. Агентность (LangGraph · [ADR-0005](adr/0005-orchestration.md))
- FR-2.1 Агентные циклы **ReAct / Plan-and-Execute** (stateful, не линейные цепочки).
- FR-2.2 Мультиагентность с делегированием (Supervisor → worker-агенты).
- FR-2.3 Вызов инструментов через **MCP**; **human-in-the-loop** на необратимых действиях.
- FR-2.4 Лимиты числа шагов/циклов и бюджета токенов (safety-net); persistence состояния (возобновление, аудит).

### FR-3. RAG (уроки 06/08; Qdrant · [ADR-0004](adr/0004-vector-db.md))
- FR-3.1 Ingestion: чанкинг → эмбеддинг → индексация.
- FR-3.2 **Hybrid search** (dense + BM25) с объединением (RRF).
- FR-3.3 **Reranking** (cross-encoder) перед подачей в LLM.
- FR-3.4 Цитирование источников; ответ «не знаю» при отсутствии контекста (анти-галлюцинации).
- FR-3.5 **Metadata / RBAC pre-filtering** — выдача только разрешённых документов.

### FR-4. Совместный поиск по БЗ (Onyx · [ADR-0008](adr/0008-knowledge-base-connectors.md))
- FR-4.1 Коннекторы к **Confluence, Jira, SharePoint** (расширяемо).
- FR-4.2 **Инкрементальная синхронизация** источников.
- FR-4.3 **Permission-aware retrieval** — наследование прав источника.

### FR-5. Интеграция (MCP · [ADR-0009](adr/0009-mcp-integration-layer.md))
- FR-5.1 Внутренние системы доступны агентам как **MCP-инструменты** (write-once).
- FR-5.2 Onyx как **MCP-сервер** — общая БЗ доступна агентам через стандартный интерфейс.
- FR-5.3 Управление набором инструментов и их правами (scoping per система/агент).

### FR-6. Guardrails и безопасность
- FR-6.1 Input-guardrails: фильтрация PII, защита от prompt-injection.
- FR-6.2 Output-guardrails: PII-маскирование, фильтр токсичности, проверка на галлюцинации.
- FR-6.3 Дисклеймер «я бот, могу ошибаться».

### FR-7. Администрирование и RBAC
- FR-7.1 Управление пользователями, ролями, группами.
- FR-7.2 ACL на документы (см. [ER](../diagrams/sequence-er.md)).
- FR-7.3 **Аудит-лог** доступа и действий (№ 99-З).

### FR-8. Наблюдаемость
- FR-8.1 Трейсинг запросов (шаги агента, вызовы инструментов).
- FR-8.2 Метрики: токены/сек, latency, стоимость запроса (FinOps).
- FR-8.3 Дашборды и алерты (OpenTelemetry + Prometheus/Grafana).

## Нефункциональные требования (NFR)

| Атрибут | Цель | Обоснование |
|---|---|---|
| **Latency p95** | ⚠ ответ ≤ 5 с (короткий), ≤ 15 с (агентный с инструментами); TTFT ≤ 1.5 с | UX живого чата; зависит от профиля и длины контекста |
| **Throughput** | ⚠ держать целевой параллелизм на 2× H100 NVL (FP8 + continuous batching) | [ADR-0006](adr/0006-kvantovanie-i-sizing-gpu.md); уточнить по нагрузке |
| **Доступность** | 99.5 % в рабочие часы; деградация без потери данных | внутренний сервис; HA-реплика vLLM на второй карте |
| **Масштабируемость** | до ~10^7 векторов (Qdrant), горизонтальный рост воркеров/индекса | [ADR-0004](adr/0004-vector-db.md); при больших объёмах — пересмотр на Milvus |
| **Безопасность** | air-gapped; TLS; секреты в Vault; web-tier в DMZ; RBAC | [ADR-0001](adr/0001-on-premise-self-hosted-llm.md); MCP/UI = поверхность атаки |
| **Приватность / соответствие** | Закон РБ № 99-З; данные в контуре; нулевой egress к внешним LLM; ретеншн/удаление | юрисдикция РБ; permission-aware retrieval |
| **Качество (GenAI)** | faithfulness и context precision выше порога на golden set (RAGAS); FP8 без значимой деградации | уроки 06/08; eval в CI/CD |
| **Explainability / аудит** | трейс шагов агента и tool-вызовов; цитирование источников | объяснимость решений, № 99-З |
| **Стоимость / TCO** | CapEx (2× H100 NVL) + сопровождение; без переменных расходов на токены | [ADR-0001](adr/0001-on-premise-self-hosted-llm.md) |
| **Сопровождаемость** | Docs-as-Code: ADR + диаграммы в Git; пинование версий (vLLM, Open WebUI, Onyx, MCP) | урок 08 (AaC); быстро меняющиеся компоненты |
| **Портируемость** | open-weight модель (Apache 2.0), OpenAI-совместимый API, контейнеризация | смена модели/UI без переписывания интеграций |
