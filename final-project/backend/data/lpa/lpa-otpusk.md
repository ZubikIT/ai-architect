# ЛПА-01. Положение о ежегодном отпуске

## 1. Продолжительность отпуска
Основной ежегодный трудовой отпуск составляет 28 календарных дней. Отдельным категориям работников предоставляется дополнительный отпуск согласно приложению 1.

## 2. Порядок подачи заявления
Заявление на отпуск подаётся не позднее чем за 14 календарных дней до его начала через корпоративный портал. Руководитель согласует заявление в течение 3 рабочих дней.

## 3. Перенос и разделение отпуска
Отпуск может быть разделён на части по согласованию с руководителем, при этом одна из частей должна быть не менее 14 календарных дней. Перенос допускается при производственной необходимости.

## 4. Компенсация
Денежная компенсация за неиспользованный отпуск выплачивается только при увольнении.
