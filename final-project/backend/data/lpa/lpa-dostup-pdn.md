# ЛПА-03. Регламент доступа к персональным данным (ограниченный)

## 1. Назначение
Регламент определяет порядок доступа сотрудников к персональным данным (ПДн) в соответствии с Законом РБ № 99-З «О защите персональных данных».

## 2. Принцип минимальных привилегий
Доступ к ПДн предоставляется только сотрудникам, которым он необходим для выполнения должностных обязанностей, по принципу минимальных привилегий и на основании ролевой модели (RBAC).

## 3. Аудит доступа
Все обращения к ПДн логируются. Журнал аудита хранится в контуре организации и доступен службе информационной безопасности.

## 4. Трансграничная передача
Передача ПДн за пределы контура организации запрещена без отдельного правового основания.
