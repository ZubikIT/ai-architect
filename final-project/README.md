# Финальный проект

Полный пакет архитектурных документов и экономическое обоснование для презентации архитектурному комитету / CTO / инвесторам.

## Целевые артефакты

- [ ] **Vision & Goals** — цели проекта, scope, метрики успеха
- [ ] **Requirements** — функциональные и нефункциональные требования
- [ ] **HLD** — высокоуровневая архитектура (контекст, контейнеры)
- [ ] **LLD** — детальный дизайн ключевых компонентов
- [ ] **ADR** — ключевые архитектурные решения с обоснованием
- [ ] **Data architecture** — схемы данных, lineage, governance
- [ ] **Security & Compliance** — модель угроз, контроли
- [ ] **MLOps & CI/CD** — пайплайны, мониторинг, rollout-стратегия
- [ ] **Infra & Sizing** — расчёт мощностей, HA, DR
- [ ] **Economics** — TCO, unit economics, ROI, build/buy анализ
- [ ] **Roadmap** — фазы внедрения, риски, зависимости
- [ ] **Презентация** — слайды для защиты

## Структура

- [`docs/`](./docs/) — документы (Vision, HLD, LLD, ADR, Security, Roadmap)
- [`diagrams/`](./diagrams/) — диаграммы C4, sequence, deployment
- [`economics/`](./economics/) — расчёты, таблицы, обоснования
